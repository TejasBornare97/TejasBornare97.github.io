What broke in testing, and the fix

Two insurers' excess tables looked identical to search

Every chunk now carries a header with its insurer, product, document and section, so a Harbourline question can't pull Northgate's table.

Vector search ranked a definition above the answer

Added BM25 keyword search and fused both rankings with Reciprocal Rank Fusion, so exact terms like "excess" count.

The model invented a £5,000,000 limit

Prompting alone didn't stop it. A check in code now flags any figure that doesn't appear in the cited sources.

AI Voice Receptionist

A voice agent that answers calls for a physiotherapy clinic. It listens, checks a real Google Calendar, books the appointment and confirms it out loud. Callers can interrupt it mid-sentence, like they would a person.

Speech recognition and synthesis run locally. There's also a text mode that runs the same agent with typed input, for fast testing.

Design decisions

Business rules live in code, not the prompt

The tools reject weekends, past dates, bad phone numbers and taken slots, and re-check the slot just before booking so two callers can't take the same time.

Interruptions have to mean it

While she's talking, the caller must be 3.5× louder than normal for about 360 ms. Coughs and echo are ignored, real speech still cuts in.

Phone numbers read as digits

Without normalisation, the TTS read a mobile number as "seven billion, eight hundred and sixty-seven million". Numbers are now spoken in UK groupings.
